БЕЗ ОЧЕРЕДИ — демонстрационный MVP

Откройте index.html в современном браузере. Сеть не требуется.

Покупатель: меню, фильтры и поиск, корзина, оформление заказа, настоящий QR-код с номером.
Сотрудник: кнопка «Панель столовой» — обработка заказов и изменение остатков.
Для демонстрации доступны два примера заказа. Сброс данных — в панели столовой.

ВАЖНО: это фронтенд-прототип. Данные и имитация оплаты сохраняются локально в браузере.
Реальных платежей, базы данных, серверного обмена, интеграции с сайтом Финуниверситета, фискализации и синхронизации разных устройств пока нет.

Проект по презентации «БЕЗ ОЧЕРЕДИ», команда «5 и точка», 2026.
